Factory Inventory Management System

Architecture overview — full-stack demo for inventory, orders, demand forecasting, and analytics

Tech Stack

Frontend
Vue 3 + Vite
Composition API, vue-router, axios. Runs on port 3000.
Backend
Python FastAPI
Pydantic validation, uvicorn server, CORS open for dev. Runs on port 8001.
Data Layer
In-memory JSON
7 JSON files loaded at startup via mock_data.py. No database.

System Architecture

Browser
Vue 3 SPA
7 views, 9 components, 3 composables. Filters & computed properties drive UI.
API Server
FastAPI
REST endpoints, Pydantic models, query-param filtering, quarter/month logic.
Storage
JSON Files
Inventory, orders, demand, backlog, spending, transactions, purchase orders.

Data Flow

1
User adjusts a filter in the UI
Selecting time period, warehouse, category, or status updates refs in the useFilters composable.
2
View calls the API client
Filter values are passed to client/src/api.js, which builds a URLSearchParams query string and issues an axios GET.
3
FastAPI receives the request
CORS middleware allows the cross-origin request from port 3000 → 8001. Route handler reads optional query params.
4
In-memory filtering
apply_filters and filter_by_month filter the in-memory lists. Month accepts direct match (2025-03) or quarter (Q1-2025).
5
Pydantic validates the response
Each endpoint declares a response_model (e.g. List[Order]), which validates and serializes the payload.
6
Vue updates reactive state
JSON is assigned to refs like allOrders; computed properties derive view-specific aggregations (totals, low-stock counts, chart data).

Key Design Choices

  • Filters as query params, not state.Server is stateless; filter logic lives once on the server.
  • Pydantic response_model on every endpoint.Schema is enforced at the boundary, not by convention.
  • Refs for raw data, computed for derived.Aggregations recompute only when source data changes.
  • Quarter and month filtering unified.Both forms accepted on the same month param via QUARTER_MAP.
  • No database.JSON files loaded once at startup; mutations don't persist.
Demo application — in-memory data, CORS open, no auth. Not production-ready without database, authentication, and security hardening.
